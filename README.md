# ejercicioTarjetas

# Practicar construyendo las siguientes tarjetas

Proyecto de práctica de diseño maquetado responsive usando HTML, CSS, la metodología **BEM** y la propiedad `clip-path`.

## Características
- Estructura semántica HTML.
- Nomenclatura BEM (`.card`, `.card__header`, `.card__action-btn--outline`).
- Cortes de fondo realizados con la propiedad CSS `clip-path`.
- Iconos dinámicos importados desde el CDN de FontAwesome.
- listo para GitHub Pages.
